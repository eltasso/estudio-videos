# Estudio de videos (web)

Hace videos de YouTube completos con **tu presentador y tu voz**, sin instalar nada: todo corre gratis en **tu** cuenta de GitHub.

- **Panel:** la página web donde entraste con GitHub.
- **Claves:** se cifran en tu navegador y quedan como *secretos* de este repo. Nadie las ve, ni vos después.
- **Cada video** corre en GitHub Actions de este repo (gratis e ilimitado porque el repo es público). Tarda 1-3 h.
  Si pasa de 6 h, sigue solo en otra máquina.
- **El video terminado** queda en *Releases* de este repo y se baja desde el panel.
